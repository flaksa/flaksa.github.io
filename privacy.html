Privacy policy

Jarvis, a personal voice assistant. Last updated: 29 October 2026.

Who uses it

Jarvis is a personal application made for and used by one person only, its owner. It is not offered to the public, and nobody else signs in to it.

What Google data it uses

Only the owner's Google Calendar, after the owner allows it on Google's consent screen. Jarvis reads the calendar's events to tell the owner about their plans, and creates, changes or deletes events when the owner asks for it by voice.

Where the data stays

  • Jarvis runs on the owner's own Windows computer. The access Google gives is stored only there, encrypted for the owner's Windows account.
  • Calendar events are not stored anywhere else and are never sold, shared with others or used for advertising.
  • To understand a spoken request and answer it, the request and the calendar events needed for that answer are sent to Anthropic's Claude API, which processes them on the owner's behalf.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Taking the access back

The owner can disconnect Google Calendar in Jarvis's settings, or remove Jarvis's access at any time at myaccount.google.com/permissions.
